# Sairaj Shirole Portfolio

Static portfolio built with HTML, CSS and JavaScript. Vercel-ready.

## Run locally

Open `index.html` directly or use VS Code Live Server.

## Deploy to Vercel

### Option 1: Vercel dashboard
1. Put the folder in a GitHub repository.
2. Open Vercel and choose **Add New Project**.
3. Import the GitHub repository.
4. Framework preset: **Other**.
5. Build command: leave empty.
6. Output directory: leave empty.
7. Deploy.

### Option 2: Vercel CLI

Install the CLI and run from this folder:

```bash
npm i -g vercel
vercel
```

Then follow the prompts.

## Important

The resume preview is generated from the supplied `Resume.pdf` and saved as `assets/resume-page.png`.
The site also keeps the original PDF so the resume can be viewed or downloaded.
